# NICoTN
## Description
- Python code for the paper: \"Empowering Tensor Network Decompositions by Nonlinear and Incompatible Tensor Contraction\",  in SIAM Journal on Imaging Sciencesg, 2026. 

- Copyright: Sheng Liu, Xi-Le Zhao, Qin Jiang, and Michael K. Ng


## Get started
- Directly run: ``Demo_NICoTR_M_order3.py`` or ``Demo_NICoTR_M_order4.py`` for an example.
